IMPLEMENTATION APPROACH
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. First, locate the global theme/variable file (e.g., 
   theme.js, variables.css, tailwind.config.js, tokens.ts) 
   and update all color and font tokens there.

2. If using Tailwind: extend the config with the new 
   color palette and font families. Map existing utility 
   classes to the new tokens where possible.

3. If using CSS Modules or styled-components: update the 
   shared theme object/provider at the root level first, 
   then cascade through components.

4. Go component by component and apply the styling rules 
   above, replacing old color values with the new variables.

5. Test on both mobile viewport (375px) and admin desktop 
   (1280px) to confirm visual consistency.

6. Do not refactor component structure — only change 
   className, style props, or CSS rules.
